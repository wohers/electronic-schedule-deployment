# Инструкция по установке

## Требования

- Windows Server или Linux;
- не менее 4 ГБ оперативной памяти;
- не менее 10 ГБ свободного места;
- доступ к сети техникума.

## Установка

1. Проверить сервер.
2. Создать резервную копию старой системы.
3. Скопировать файлы приложения.
4. Создать базу данных.
5. Заполнить настройки.
6. Запустить приложение.
7. Проверить журнал ошибок.
8. Выполнить контрольное тестирование.
