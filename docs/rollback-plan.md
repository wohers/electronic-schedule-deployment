# План отката

## Откат выполняется, если

- приложение не запускается;
- вход пользователей невозможен;
- нет соединения с базой данных;
- основные функции не работают;
- обнаружена потеря данных.

## Действия

1. Сообщить ответственным.
2. Остановить новую версию.
3. Сохранить журналы ошибок.
4. Восстановить предыдущую версию и базу данных.
5. Запустить систему и проверить функции.
6. Уведомить пользователей и зарегистрировать инцидент.
